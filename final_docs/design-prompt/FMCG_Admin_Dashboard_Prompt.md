# Enterprise FMCG Admin Dashboard UI Prompt

Create a modern enterprise-grade **mobile ERP Admin Dashboard** for an
FMCG wholesale distribution business. Match the visual language of
Blinkit/Zepto: clean white surfaces, deep green primary (#0B6B3A),
rounded 16-20px cards, subtle shadows, thin dividers, SF/Inter
typography.

## Overall Layout

A wide workflow board showing connected mobile screens in sequence.
White background. Top workflow header with numbered modules and arrows.

## Workflow

1.  Dashboard
2.  Sales Orders
3.  Order Details
4.  Purchase
5.  Purchase Details
6.  Payments
7.  Cash & Bank
8.  Vehicles
9.  Inventory
10. Users
11. Customer Ledger

Each mobile screen uses: - Android style status bar - Green app bar -
Bottom navigation - Rounded cards - Consistent spacing (8/16/24 grid)

## Screen Details

### Dashboard

KPIs: - Today's Sales - Total Orders - Receipts - Payments -
Outstanding - Low Stock

Recent activity list and quick actions.

### Sales Orders

Tabs: All, Pending, Delivered, Cancelled. Order cards show: Customer,
Order ID, Date, Amount, Status.

### Order Details

Customer info, salesman, address, products, quantities, totals. Buttons:
Edit Order, Duplicate.

### Purchase

Supplier list with outstanding balance. CTA: Add Supplier.

### Purchase Details

Supplier order timeline, received items, invoice preview.

### Payments

Customer/Supplier tabs. Cash, UPI, Cheque indicators. Daily totals.

### Cash & Bank

Opening cash, cash received, UPI, bank deposits, payments, closing cash.

### Vehicles

Fleet list with Available / Running / Maintenance.

### Trip Details

Driver, truck, stops, loading capacity, completion.

### Inventory

Summary cards: Available, Low Stock, Expired. Categories and product
list.

### Product List

Product image, SKU, stock, expiry, low stock badge.

### Users

Admins, Salesmen, Drivers, Loaders, Cashiers with active status.

### Customer Ledger

Outstanding balance, credit limit, payment history, orders.

## UX Rules

-   One primary CTA per screen.
-   Large touch targets.
-   Simple labels.
-   Enterprise but minimal.
-   Consistent green accent.
-   Flat modern design.
-   High information density without clutter.

## Style

Photorealistic high fidelity mobile UI mockups, Figma quality,
enterprise SaaS, premium, soft shadows, clean typography, pixel-perfect
alignment.
